# Instituto Raízes

Site institucional fictício de uma ONG de educação e segurança alimentar, desenvolvido em HTML5 semântico como atividade de front-end.

## Páginas

- index.html: apresentação, projetos em destaque e contato
- pages/sobre.html: missão, história e equipe
- pages/projetos.html: frentes de atuação, voluntariado e doação
- pages/cadastro.html: formulário com validações nativas do HTML5
- pages/contato.html: formulário de contato

## Estrutura

- css/: estilos
- js/: scripts
- img/: imagens

## Observações

Nome da ONG, textos e dados de contato são fictícios.
